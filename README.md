# 我的任务表 📋

一个**单文件**的待办/计划任务表，手机、平板、电脑浏览器都能直接用，无需安装、无需联网。

## 功能

- 📱 **移动端友好**：响应式布局，手机 / 平板 / 电脑都适配
- 🏷️ **自定义分类**：可创建分类并设置颜色，按分类筛选任务
- 🌲 **层级任务**：大任务下挂分支小任务，可展开 / 收起，父任务自动显示完成进度
- ✅ **勾选完成**：父子任务分别勾选，完成项划线置灰
- 💾 **本地存储**：数据保存在浏览器 localStorage，刷新 / 关闭不丢失
- 📤 **导入 / 导出**：一键备份为 JSON 文件，方便换设备迁移

## 使用方式

直接用浏览器打开 `任务表.html` 即可。

> 想把数据在手机和电脑间同步？导出 JSON 备份后，在另一台设备「更多 → 导入数据」即可。

## 数据说明

- 数据只存在**你自己的浏览器里**，不会上传到任何服务器。
- 建议定期用「更多 → 导出数据」备份，避免清空浏览器缓存导致数据丢失。
