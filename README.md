# 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript（Canvas）编写的经典「坦克大战 / Battle City」网页游戏，单文件实现、无需任何依赖，打开即玩。

## ✨ 特性

- 🕹️ 经典玩法：操控己方坦克，守住基地（旗帜），消灭所有敌人
- 🧱 可破坏砖墙、不可破坏钢墙、可穿越的水面、可藏身的草丛
- 🤖 敌方 AI：随机巡逻 + 一定概率追击玩家并射击
- 🎁 道具系统：❤ 加命 · 🛡 护盾 · ⭐ 火力升级
- 🎵 Web Audio 音效（射击 / 爆炸 / 道具 / 关卡）
- 📈 得分、生命、关卡、剩余敌人，难度随关卡递增，无尽关卡
- 🎨 复古像素风，画面简洁清晰

## 🎮 操作

| 按键 | 作用 |
| ---- | ---- |
| 方向键 / WASD | 移动坦克 |
| 空格 / J | 射击 |
| P | 暂停 / 继续 |
| M | 静音 / 取消静音 |
| 回车 | 开始 / 下一关 / 重新开始 |

## 🚀 运行方式

### 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何环境。

### 在线游玩（GitHub Pages）

1. 在 GitHub 仓库的 **Settings → Pages** 中，将 Source 设为 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`。
2. 稍等片刻，即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。

## 🛠️ 技术说明

- 基于 HTML5 Canvas 渲染，13×13 网格地图，每格 40px。
- 游戏循环使用 `requestAnimationFrame`，按帧时间差（delta time）更新，保证不同刷新率下速度一致。
- 坦克移动采用网格吸附 + 四角碰撞检测，转向平滑、不会卡在半格。
- 地图使用字符串数组定义，方便扩展新关卡（在 `MAPS` 数组中追加即可）。
